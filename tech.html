Programar é um esporte de repetição. Pratique pouco, todo dia, com projetos reais — e use o Git desde o primeiro arquivo.

Ver princípios ↓
tech.principios()

Três hábitos que fazem mais diferença do que qualquer curso.

  1. 1

    Um pouco todo dia

    30 minutos diários ensinam mais que 5 horas no fim de semana. Constância cria memória.

  2. 2

    Construa projetos reais

    Escolha um problema seu (como este site!) e resolva com código. Tutoriais só levam até certo ponto.

  3. 3

    Use Git desde o início

    Versione tudo e leia código de outras pessoas no GitHub. Revisar é uma forma rápida de aprender.

const meta = "evoluir";
while (vivo) {
  praticar(30); // min
  commit(meta);
}
